# 配置参考

[返回 README](../README.md)

[deployment.env.example](../examples/deployment.env.example) 是供交接填写的示例模板，Python 脚本不会自动加载它。所有口令、token 与数据库密钥为空；真实值保存在部署主机受限文件或独立密码管理系统中。

## 地址与版本的修改位置

| 配置 | 通用设备入口 | 历史专用脚本位置 |
|---|---|---|
| 堡垒机 Tailscale IPv4 | `--bastion-ip` | 安装器 `IP`；LAN 脚本 `TAIL`；GUI/SSH 限制脚本中的固定地址 |
| 下位机 IPv4 | `--edge-ip auto` 或明确传入本机地址 | `configure-nvidia-xrdp.py`、首台 RDP/修复脚本内固定地址校验 |
| 设备名称 | `--name` | 历史页面记录不作为新设备命名规范 |
| Linux 开发用户 | `--user`，必须已存在且非 root | 首台脚本固定使用历史账号 |
| LAN 网页/Koko 地址 | 官方 config 与 Compose 端口映射 | LAN 两脚本 `LAN`，GUI 后续覆盖需同步 |
| 版本、目录、主机名、USB | 服务器部署专用配置 | 安装器 `VERSION`、`HOME_DIR`、`STAGING`、`INSTALLER`、`CONFIG`、`DATA`、`STATE`、`main()` 守卫 |
| 镜像摘要 | 按固定 registry digest 获取 | `EXPECTED_IMAGES`、`ARCHIVE_SHA`；GUI/executor 中固定摘要 |

历史代码中的真实地址、机器名和 UUID 作为原部署样例保留，不是新环境默认推荐值。更换地址还应同步 TLS SAN、`SERVER_NAME`、`DOMAINS`、Web HTTPS、Koko 端口、tailnet 策略和下位机防火墙。

## 服务器关键配置

| 配置组 | 字段 / 路径 | 作用 |
|---|---|---|
| 私有配置 | `/opt/jumpserver/config/config.txt` | 部署实值，禁止提交 |
| 加密与注册 | `SECRET_KEY`、`BOOTSTRAP_TOKEN` | 生成或恢复同一环境配套值 |
| 数据库/缓存 | `DB_*`、`REDIS_*` | 主机、端口、用户名、数据库和运行时口令 |
| Web/TLS | `HTTP_PORT`、`HTTPS_PORT`、`SERVER_NAME`、`DOMAINS`、`SSL_CERTIFICATE*` | 监听与证书；绑定地址与容器内部端口不可混淆 |
| 组件 | `*_ENABLED`、`USE_XPACK` | 历史社区版按实际所需服务启用 |
| 容器网络 | `DOCKER_SUBNET`、`USE_IPV6` | 避免与 LAN/tailnet 冲突 |
| 数据 | `VOLUME_DIR=/data/jumpserver` | 与部署备份规划一致 |
| 审计保留 | `TERMINAL_SESSION_KEEP_DURATION`、`*_LOG_KEEP_DAYS` | 原脚本有历史配置，不证明归档作业已完成 |
| 自定义覆盖 | `compose/laptop.yml`、`laptop-bootstrap.yml` | 生成的实际文件未从 root 完整采集 |

原安装器生成 48 位随机应用/数据库密钥，创建受限管理员凭据文件；这些文件从未复制到发布仓库。上游安装器运行期间可能显示新生成的密钥，不要将完整安装输出上传 issue 或截图。

## 通用桌面参数

`--user` 和 `--bastion-ip` 必填；`--edge-ip` 默认 `auto`，指定时要求属于本机；`--name` 默认主机名；`--apply` 才安装；`--install-gnome`、`--replace-startwm` 各自允许对应的额外变更。

向导增加 `--from-stage tailscale|desktop|assets|finalize`，从明确阶段继续。`finalize` 阶段只输出命令，向导本身不会自动封堵。

收尾脚本提供 `apply|confirm|status|rollback|boot|auto-rollback`；`apply` 需要 `--bastion-ip`，`--minutes` 默认 15，可选 5 至 60。`boot` 和 `auto-rollback` 是系统服务/计时器内部入口，日常按流程使用前四项。

## 诊断参数与发布改动

`diagnose-jumpserver-import.py` 运行时输入要检查的用户名；`diagnose-jumpserver-operator-login.py` 交互输入用户名与待验证初始口令，口令不回显，不通过进程参数传入。无用户名或空口令时退出。查询字段和只读诊断逻辑保留；输出仍可能包含个人登录记录，不应提交到仓库。
