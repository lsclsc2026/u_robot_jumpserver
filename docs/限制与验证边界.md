# 限制、历史状态与本次验证边界

[返回 README](../README.md)

## 来源能证明什么

本仓库基于 2026-09-13 本机交接目录中的 28 个本地脚本、文档与镜像元数据整理。历史文档记录过服务器六服务起步、之后加 LAN 与 Lion；记录过部分设备的 xrdp/sesman 和端口检查。它们不是本次实时容器、资产、防火墙或重启状态的证明。

原交接时服务器普通用户可读资料得到采集；root 专有配置/包装器/覆盖不完整，设备实时文件也没有完整采集。用户、资产、授权的当前页面记录在数据库内，本仓库没有数据库导出，不能从源码重建原有真实用户和所有授权。

## 本次只检查发布材料

- 只在本机复制审阅过的源码、生成中文文档、检查文件大小、源文件哈希、静态凭据特征和新文档相对链接。
- 未运行项目 Python/Shell 脚本、测试文件、编译器、Docker、服务状态命令或部署操作。
- 未连接下位机、打开资产终端、进行 SSH/RDP 连接、机器人控制或实机功能验收。
- 网页截图仅记录管理台与用户资产页面；没有视频，不作为连接、录像、回放、防火墙或重启验证。

凭据输入相关修改仅做静态审阅；没有执行交互诊断来声称功能已测试。仓库保留五个原有 `test_*.py` 文件供之后获准时使用，发布本轮未执行。`test_image_loading.py` 依赖脚本同目录下额外 `images/manifest.json` 和镜像材料，普通源码克隆并不自带完整测试运行环境。

## 已知适用范围

服务器归档仅 `linux/amd64`，设备通用脚本显式仅支持 Ubuntu 22.04。其他 Ubuntu、JetPack、GNOME、xrdp、架构和图形驱动组合需各自验收。

固定主机脚本包括旧地址、账号、磁盘 UUID、目录和镜像哈希；它们作为部署源代码留存，不是即插即用工具。Tailscale 首次安装使用线上稳定版脚本，原源码未锁定该外部脚本内容。安装器与镜像版本是来源快照版本，不宣称是最新或已完成安全升级。

关闭 NoMachine 与限制 SSH/RDP 只涵盖这些入口；其他远控、ROS、控制 API、浏览器服务和串口等不在该规则覆盖范围。拥有最高系统权限者可修改规则。共享 Linux 账号不提供用户桌面隔离。
